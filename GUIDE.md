# Запуск на Samsung The Frame QN55LS03BAFXZC

Сборка: **2026.10.23.4**. Lampa и KinoPub уже настроены вместе.
Компьютер, Cloudflare и собственные API-ключи для запуска не нужны.

## 1. Установить Media Station X

1. На пульте нажми **Home → Apps → Поиск**.
2. Найди **Media Station X** и установи из магазина Samsung.
3. Запусти приложение.
4. Открой **Settings → Start Parameter → Setup**.
5. Введи ровно:

   `id:rgh:dearlordylord`

6. Включи **замок / HTTPS**, если он предлагается, и подтверди настройку.
7. Должно появиться название **«Lampa · личная сборка»**.
8. Выбери плитку **«Открыть Lampa + KinoPub»**. Если MSX спросит об открытии ссылки, подтверди.

Это запускает нашу сборку. Не вводи адреса из старых инструкций, kpms.cc или адрес исходного автора плагина.
Плагин отдельно добавлять не нужно: он уже встроен.

## 2. Подключить свой KinoPub

1. В Lampa открой **шестерёнку → KinoPub → Авторизоваться**.
2. Дождись кода из **пяти символов**; в нём могут быть буквы.
3. На телефоне/компьютере открой свой привычный сайт KinoPub — тот, где ты уже видел **«Активация устройства»**.
4. Введи туда код с телевизора. Пароль от аккаунта вводится только на сайте KinoPub.
5. Подожди несколько секунд: окно на телевизоре должно закрыться после подтверждения.

Каждый телевизор/браузер получает свой код. Код из прошлой проверки использовать не нужно.
Если он истёк, закрой окно кнопкой «Назад» и открой «Авторизоваться» ещё раз.

## 3. Посмотреть фильм или сериал

1. Найди фильм/сериал через поиск Lampa. Каталог здесь — TMDB; он может показывать тайтлы, которых нет в KinoPub.
2. Открой карточку и выбери кнопку **KinoPub**.
3. Если показаны совпадения, выбери нужное. Для сериала выбери сезон и серию.
4. Для первой проверки оставь **Макс. качество: 1080p**, **Формат потока: Авто (HLS2)**, **Внешние субтитры: Нет**.
5. Стрелки и OK управляют меню; во время просмотра используй OK/Play-Pause и «Назад».

Вход через код и загрузка каталога проверены в Chrome. Воспроизведение с реальным аккаунтом и аппаратный плеер этого Samsung ещё не проверены.

## Откуда фильмы и как выбрать оригинал

Главная Lampa — каталог TMDB. Она не показывает наличие в KinoPub и не меняется
после входа. Видео в этой сборке открывается через кнопку **KinoPub** в карточке:
плагин ищет тайтл и запрашивает файл у API KinoPub. Других встроенных видеоисточников нет.
Для аниме сверяй год/название: аниме, игровой фильм и продолжение — разные записи.

В экране после кнопки KinoPub теперь видна подпись **KinoPub · название**.
До запуска выбери озвучку в фильтре сезона/озвучки: **JPN** — японская,
**ENG** — английская, **RUS** — русская. Сборка не скрывает языки, полученные от API.
Если выбираешь дополнительную дорожку, клиент использует многодорожечный HLS,
когда он доступен. Если всё равно слышна другая озвучка, попробуй формат HLS
в настройках и запусти видео заново; HLS2 может содержать только одну дорожку.
Факт наличия дорожек на сайте не гарантирует одинаковую поддержку потока плеером ТВ.

Субтитры: Настройки → KinoPub → Внешние субтитры → Да; перезапусти видео,
затем выбери нужный язык значком субтитров в панели плеера (OK).

Обновление с первой сборки: полностью закрой MSX и открой заново. Если остался
старый экран/список дорожек, прямой адрес с обходом кеша:
https://dearlordylord.github.io/lampa/?v=4 . Локальные токены и история не удаляются.

## Если раньше не было кнопки KinoPub и выбора озвучки

В сборке 3 исправлена совместимость с карточками текущей Lampa. На карточке
теперь есть **отдельная видимая кнопка KinoPub**, а не только общая «Смотреть».
После её нажатия открой сверху кнопку с сезоном/текущей озвучкой: в списке
сначала идут **«Озвучка: …»**, затем сезоны. Для Bleach выбирай **JPN**.
В меню проигрывателя при этом может оставаться одна подпись выбранной озвучки;
выбор делается **до** запуска серии в этом списке.

## Если не получается

**MSX не принимает `id:rgh:dearlordylord`.** Обнови Media Station X через магазин Samsung. Если не помогло, открой в телевизионном приложении **Internet** адрес `https://dearlordylord.github.io/lampa/`. Это запасной способ загрузки той же сборки; возможности плеера браузера могут отличаться. Можно сначала открыть этот адрес на ноутбуке, проверить каталог и выдачу кода; вход на ноутбуке не авторизует телевизор.

**Media Station X отсутствует в магазине.** Используй браузерный способ выше. Не меняй регион Smart Hub и не устанавливай WGT из случайных архивов ради этой проверки.

**В MSX виден launcher, но Lampa не открывается.** Выбери плитку OK, подтверди открытие ссылки. Запасной прямой адрес — `https://dearlordylord.github.io/lampa/`.

**Нет раздела или кнопки KinoPub.** Проверь адрес сборки: именно `dearlordylord.github.io/lampa/`. Закрой и заново открой MSX. Не устанавливай дополнительный плагин поверх встроенного.

**Чёрный экран / нет звука.** Начни с 720p и Авто (HLS2). Можно попробовать **HLS**, затем перезапустить воспроизведение. HLS4 может зависать на Samsung. Настройки плеера Lampa — внутренний плеер, без внешнего Android-приложения.

**Не та озвучка или она не переключается.** HLS2 может содержать одну аудиодорожку. Попробуй HLS и выбери озвучку перед воспроизведением. Авторский прокси намеренно отключён, поэтому выбор озвучки и 4K пока не гарантированы.

**Пишет, что не удалось получить поток / нет постеров.** Проверь Интернет. В сборке разрешены только API KinoPub, TMDB и известные семейства CDN. При смене доменов сервисом может понадобиться обновление списка. Не включай для исправления чужой прокси и не отправляй полные ссылки на видео: они могут содержать временный доступ. Достаточно сообщить текст ошибки и имя домена.

**Тормозит загрузка.** Локацию сервера устройства меняй на своём сайте KinoPub, если такая настройка доступна. Плагин не перенастраивает устройство автоматически на Россию/Украину/Беларусь.

## Что здесь отключено

Удалённый терминал JavaScript и WebSocket, CUB-вход и облачная синхронизация, внешние служебные плагины, магазин расширений, отправка истории и логов, сервер автора KinoPub-плагина, сторонние API/TMDB-прокси. Плагин KinoPub, история и настройки остаются локальными; код и библиотеки загружаются из нашего репозитория. Просмотр и запросы к самим KinoPub/TMDB/CDN, конечно, доступны этим сервисам.

## Выход и возврат назад

- В Lampa: **Настройки → KinoPub → Выйти из аккаунта** — удаляет локальные токены.
- Чтобы отозвать доступ полностью, удали устройство на своём сайте KinoPub.
- В MSX: **Settings → Start Parameter** — можно изменить или сбросить параметр и вернуть прежний запуск.
- Установка не меняет прошивку телевизора и не требует Developer Mode.

### Обновление и аудио: сборка 4

Чтобы перезагрузить приложение с пульта: **Настройки → Кеш и данные → Очистить кэш → Только кеш**. Приложение перезагрузится через 3 секунды; токены KinoPub сохранятся. Это очистка кэша данных Lampa, а не обещание полной очистки HTTP-кэша телевизора. Питание отключать для обычного обновления не требуется.

До запуска выбери озвучку в кнопке над сериями. Сборка 4 передаёт выбор настоящим дорожкам Lampa и больше не подменяет их список единственной надписью выбранной озвучки. Если дорожка не найдена или неоднозначна, появится уведомление: выбери её в настоящем меню дорожек проигрывателя. Проверено локально с механизмом переключения из поставляемой Lampa; Samsung и звук Bleach на устройстве разработчика не проверены.
